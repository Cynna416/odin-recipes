# odin-recipes

## Milestone-1: HTML Build

*The purpose of this section is to put in use learned HTML.*

### Skills Focus

The following are the main HTML focus points for this milestone:

- File structure 
  - images folder for images
  - recipes folder for recipe pages
  - index.html in root project folder
- Boilerplate and meta-tag info used for each `.html` file
- Use of headings (`h1`, `h2`, etc) with `h1` as main heading
- Use of ordered and unordered lists
- links to other pages and to outside websites
- Use of images with `alt` attribute
- Using terminal and CLI to communicate between local git and Github
- Practice writing git commit messages

### What I Accomplished

For this Milestone, every page created has a boilerplate with meta-tags and a title inside the `head` element

Inside the `body` element I created a Homepage (`index.html`) and 3 separate recipe pages. The homepage contains links to each page, as well as a smaller image for each recipe name that can be clicked and enlarged for easier viewing.

Each recipe page is laid out as such:

- A `header` with `nav` that links back to the homepage
- A `main` that contains:
  - heading (h1) that is the name of the recipe
  - A "Description" sub-heading with a brief description of the recipe.  I also included prep time, cook time, and servings in this section.
  - An "Ingredients" sub-heading with an unordered list of ingredients for the recipe
  - A "Steps" subheading with an ordered list of directions for completing the recipe
- I also added a footer to each recipe page that contains a link to the recipe that was used.
