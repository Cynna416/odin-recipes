# odin-recipes

## Milestone-1: HTML Build

*The purpose of this section is to put in use learned HTML.*

For this Milestone, I created a Homepage (index.html) and 3 separate recipe pages. The homepage contains links to each page. Each recipe page is laid out as such:

- A `header` with `nav` that links back to the homepage
- A `main` that contains:
  - heading (h1) that is the name of the recipe
  - A "Description" sub-heading with a brief description of the recipe.  I also included prep time, cook time, and servings in this section.
  - An "Ingredients" sub-heading with an unordered list of ingredients for the recipe
  - A "Steps" subheading with an ordered list of directions for completing the recipe
- I also added a footer to each recipe page that contains a link to the recipe that was used.

*(This project assignment can be found on The Odin Project: [Project: Recipes](https://www.theodinproject.com/lessons/foundations-recipes))*
